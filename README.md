# 🐍 Neon Snake Arcade Game

A fast-paced, cyber-themed 2D Snake game built using modern HTML5 Canvas, CSS3, and JavaScript. Features synthesized sound effects, dynamic particle explosions, responsive mobile touch / virtual D-pad controls, and persistent high scores.

🎮 **[Play the Live Demo Here](https://aashfaak.github.io/Neon-Snake-Game/)**

---

## ✨ Features

* **Cyberpunk Neon Aesthetic:** Dark-mode grid layout with vibrant canvas glowing effects and smooth animations.
* **Web Audio API:** Synthesizes retro arcade sounds directly in code (no external MP3 files needed).
* **Particle Physics Engine:** Exploding neon particles when collecting food or crashing.
* **Cross-Platform Play:** Supports keyboard controls (`Arrow Keys` / `WASD`) for desktop, along with touch controls and a virtual D-pad for mobile.
* **Customizable Difficulty & High Score:** Play on Easy, Medium, or Hard speed settings with scores saved in `localStorage`.

---

## 🛠️ Tech Stack

* **HTML5:** Game structure and `<canvas>` 2D rendering area.
* **CSS3:** Flexbox layout, glowing drop-shadow effects, CSS variables, and overlays.
* **JavaScript (ES6+):** Game loop (`requestAnimationFrame`), collision logic, particle systems, and audio synthesis.
